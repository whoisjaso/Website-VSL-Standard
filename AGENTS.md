# Agent instructions

For ANY website, landing page, funnel page or VSL page you plan, design, build or audit, follow [SKILL.md](SKILL.md) in this repo, step by step, before writing code.

- Start with Step 1: fill [templates/client-intake.md](templates/client-intake.md) with the client.
- Copy values from [reference/tokens.css](reference/tokens.css) and [reference/motion.js](reference/motion.js); swap only the colors for the client's palette.
- Nothing ships until every gate in Step 7 passes. Prod deploys need the site owner's explicit OK.
- Never copy olaceo-only facts (palette, font, logo, voice, ICPs) onto a client site.
